# Contributing

Contributions should remain focused on read-only Android kernel and image analysis.

Useful contributions include parser compatibility for additional Android image versions, malformed-input tests, kernel metadata detection, kallsyms/BTF/ELF/DTB analysis, reproducible fixtures with clear redistribution rights, and documentation and provenance improvements.

Please identify upstream projects when adapting implementation ideas or code, and preserve applicable license and attribution requirements.

Do not add exploit execution, privilege escalation, automatic exploit-offset generation, or code that adapts exploit payloads to a target kernel.
